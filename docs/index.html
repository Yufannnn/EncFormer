Input sequence

EncFormer repeats encrypted GPU kernels and secure MPC protocols across its Transformer layers.

01 / THE PROBLEM

Privacy shouldn't
bring everything to a halt.

When a service processes private text, it usually sees it. Encryption can protect the input—but naïve encrypted Transformer computation is expensive. EncFormer changes how the cryptographic pieces fit together.

01

Privacy by design

The client encrypts its input. The server evaluates the model without seeing plaintext activations; only prescribed outputs are revealed.

GPU-accelerated FHE handles projections and attention kernels while layouts are chosen to compose without expensive remapping.
